You will be writing your code in `sketch.js` within the main folder - not the `example/` folder.

To run your code open `index.html` and then click on the *Go Live* button in the bottom right.  This will open a browser page, and should refresh every time your work saves.

Recreate [this image](https://openprocessing.org/sketch/1030384/embed/?plusEmbedHash=df978b4e&userID=175929&plusEmbedTitle=true&show=sketch).  Feel free to add your own touches, but make sure all of the objects below are there.

- Line up your code - all code should be indented (once) inside the draw() function.
